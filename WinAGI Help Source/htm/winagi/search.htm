Searching and Replacing Text

All editors in WinAGI that manage text elements of game resources (logics, include (text) files, OBJECT file, WORDS.TOK file, global defines list) use a common engine to manage search and replace operations. The primary method for searches is to display the Find/Replace dialog:

The Find/Replace dialog will remain on top of all WinAGI editors until you dismiss it by clicking Close. To switch to 'replace' mode, click the Replace button.

Enter the search string in the 'Find what:' text box. WinAGI does not support wild card searches.

The search scope can be one of the following: the current document, all editors currently open, or the entire project (all game resources).

    • Current document: searches only the currently active open resource/tool editor
    • All Open documents: searches all open resource editors
    • Entire Project: (only available if a game is open) searches all logics and include files in a game whether they are open for editing or not; as well as all other open logic or text editors

The direction of the search can be set to:

    • Next: searches forward, until end of search scope is reached, loops back to the beginning of the search scope, then continues until starting point of search is reached
    • Previous: searches backward, until beginning of search scope is reached, loops back to the end of the search scope, then continues until starting point of search is reached

Find All

The Find All feature will locate all instances of the specified search term and display them as a list in the Search tab (which shares space with the Errors and Warning list. You can double-click an entry to immediately move to the specified line in the specified resource.

When using the Find All feature when the scope is set to Entire Project, in addition to all game logics, the results also include the game's OBJECT and WORDS.TOK files and the global defines list.

When the Search tab is visible, you can also conduct searches using the Search toolbar. It functions exactly the same as the Find dialog.

 

Search and replace features vary slightly depending on the currently active editor:

Logics and Text Editors

When beginning a search from an open logic or text editor, all search features are available. The 'Entire Project' scope includes all logics and include files as well as all other open logic and text editors; it does not include the OBJECT or WORDS.TOK files.

OBJECT Editor

When beginning a search from an OBJECT file editor, the search scope is limited to the active editor.

WORDS.TOK

When beginning a search from a WORDS.TOK file editor, the search scope is limited to the active editor. Because words are limited to only lower case letters, the match case option is always ignored.

global defines

When beginning a search from a global defines editor, the search scope is limited to the active editor. The search will look for a match in define names, define values and define comments.

Find in Logics

For the OBJECT, WORDS.TOK and global editors, the Find in Logics command on the Edit menu allows you to search for a specific term (inventory item, word, global define name) in all of your logic resources. To use this feature, select the item you wish to search for, then choose the Find in Logics command.

WinAGI will search all logics in your game for the selected item. Note that changing any of the search parameters will switch to the normal 'search in logics' mode.

For word searched, you can optionally search for word synonyms in addition to the selected word:

    • If you select an individual word from the word list of a group, then WinAGI assumes you want to search for that specific word.
    • If you select a group, WinAGI assumes you want the search to include synonyms (all words in the group).

In either case, you can change the synonym search option by using the 'Include Synonyms' option on the Find dialog. With this option enabled, WinAGI will find all instances of all words in this group.
