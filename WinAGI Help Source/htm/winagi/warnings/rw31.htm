Resource Load Warning RW31

globals.txt file has one or more invalid entries

This warning indicates one or more define entries in the globals.txt file are invalid. This could mean either the define name or define value would cause an error if they are used in a logic. Examples include a define name with invalid characters, a duplicate name, values that aren't valid numbers or argument markers, etc.

It may also indicate a define name that is overriding another global define, a reserved variable/flag, or a resource ID. While not an error, overrides are not normally intentional.

You can open the file in the globals editor to examine it, and make any needed corrections. Items that have an error will be highlighted in red bold text, and warnings will be highlighted in orange text.
